# Топ-идеи из лучших открытых музыкальных плееров

Собрал и структурировал самые сильные решения из 19 топовых репозиториев ([LX Music](https://github.com/lyswhut/lx-music-desktop), [Spotube](https://github.com/team-spotube/spotube), [YesPlayMusic](https://github.com/qier222/YesPlayMusic), [MusicFree](https://github.com/maotoumao/MusicFree), [Navidrome](https://github.com/navidrome/navidrome), [Nuclear](https://github.com/nukeop/nuclear), [Koel](https://github.com/koel/koel), [YouTube Music Desktop](https://github.com/th-ch/youtube-music), [Feishin](https://github.com/jeffvli/feishin), [Strawberry](https://github.com/strawberrymusicplayer/strawberry), [Tauon](https://github.com/Taiko2k/TauonMusicBox), [Dopamine](https://github.com/digimezzo/dopamine), [DeaDBeeF](https://github.com/DeaDBeeF-Player/deadbeef) и др.).

Отметьте галочками `[x]` то, что вы хотите добавить в наш плеер:

---

## 🎨 1. Визуал и Интерфейс (UI / UX)
- [x] **Режим полного погружения (Now Playing)** — разворачивание экрана трека с анимированным градиентным размытием обложки на весь фон в стиле Apple Music *(YesPlayMusic)*.
- [x] **Компактный мини-плеер поверх всех окон (Always on Top / PiP)** — маленькая плавающая плашка с обложкой, управлением и плейбаром, пока вы играете или работаете в других программах *(YesPlayMusic / Dopamine / Tauon)*.
- [x] **Темы оформления** — готовые цветовые схемы (Pure Onyx, Cyberpunk Neon, Midnight Blue, Dracula, Nord) *(Supersonic / Dopamine)*.
- [ ] **Анимированный винил и волны** — переключаемый режим между крутящимся винилом, кассетным плеером и реактивным спектроанализатором *(LX Music / Strawberry)*.
- [x] **Плавное появление и переходы** — кинематографичные переходы между экранами без рывков.

---

## 🔊 2. Аудиодвижок и Hi-Fi Качество
- [x] **Кроссфейд (Crossfade)** — плавное бесшовное перетекание одной песни в другую с настраиваемым временем наложения (1-6 сек) *(LX Music / Spotify)*.
- [x] **Воспроизведение без пауз (Gapless Playback)** — предзагрузка следующего трека в буфер для моментального старта без задержек и щелчков между композициями *(Tauon / Strawberry)*.
- [x] **Выравнивание громкости (ReplayGain / Volume Normalization)** — автоматическое приведение всех треков к единой громкости (тихие треки усиливаются, громкие не глушат) *(Tauon / DeaDBeeF)*.
- [x] **Расширенный 10-полосный эквалайзер** — с пресетами (Rock, Metal, Electronic, Hip-Hop, Acoustic) и ручной подстройкой частот *(Strawberry / Clementine)*.
- [x] **Прямой вывод звука (WASAPI Exclusive)** — возможность отправки побитового аудиопотока напрямую в ЦАП/наушники в обход стандартного микшера Windows *(DeaDBeeF / Strawberry)*.
- [ ] **Бейдж параметров звука** — вывод реального формата (например: `FLAC 24-bit 96 kHz` или `MP3 320 kbps`) в строке плеера *(Metrolist / Strawberry)*.

---

## 🎤 3. Синхронизированный текст песен (Lyrics)
- [x] **Караоке-тексты (LRC)** — динамическая прокрутка слов песни в такт музыке с подсветкой текущей строки *(LX Music / YesPlayMusic)*.
- [ ] **Плавающий текст поверх всех окон (Desktop Floating Lyrics)** — отображение бегущей строки со словами прямо поверх рабочих окон или игр *(LX Music)*.
- [x] **Автопоиск текста** — автоматическая подгрузка текста песни из открытых баз (LRCLIB, Musixmatch) при начале воспроизведения.

---

## ⚡ 4. Управление и Интеграция с Windows
- [ ] **Глобальные горячие клавиши (Global Hotkeys)** — управление треками (Play/Pause, Next, Prev, Volume) даже когда плеер свернут в трей или вы в игре *(LX Music / Dopamine)*.
- [x] **Discord Rich Presence** — отображение в вашем статусе Discord названия песни, исполнителя, обложки и прогресса воспроизведения *(YouTube Music Desktop / Spotube)*. 
но включать по желанию
- [x] **Медиа-уведомления Windows** — всплывающее системное уведомление в углу экрана с обложкой и кнопками при переключении трека *(YouTube Music Desktop)*.
- [x] **Сворачивание в системный трей (Tray)** — плеер прячется около часов Windows и продолжает играть в фоне, не занимая место на панели задач *(Dopamine / Clementine)*.
- [x] **Таймер сна (Sleep Timer)** — автоматическая плавная остановка воспроизведения через заданное время (15, 30, 60 мин) *(Spotube)*.

---

## 📚 5. Медиатека, Очередь и Сортировка
- [x] **Умная сортировка и группировка** — разделение медиатеки по исполнителям (с их фото), альбомам, годам и жанрам *(Feishin / Navidrome / Clementine)*.
- [x] **Перетаскивание в очереди (Drag & Drop Queue)** — возможность хватать мышкой треки в списке воспроизведения и менять их порядок местами *(Museeks / Koel)*.
- [x] **Умные плейлисты (Smart Playlists)**:
  - Любимые (треки с лайками)
  - Часто прослушиваемые
  - Недавно добавленные
  - Забытые фавориты (то, что нравилось, но давно не слушали) *(Navidrome)*.
- [x] **Редактор тегов прямо в приложении** — возможность исправить название, исполнителя, альбом или вручную заменить обложку трека *(Strawberry / DeaDBeeF)*.
- [x] **Импорт/экспорт плейлистов** — сохранение и загрузка списков в стандартном формате `.m3u8` *(Tauon)*.

---

## 🌐 6. Источники и Скачивание
- [x] **Умный кэш (Smart Offline Cache)** — если слушаете трек онлайн, он автоматически сохраняется на диск без необходимости нажимать кнопку скачивания *(Spotube)*.
- [x] **Агрегатор источников (Fallback Search)** — если трек недоступен в одном месте, плеер автоматически подтягивает аудиопоток с альтернативного источника (YouTube Music / SoundCloud) *(Nuclear / MusicFree)*.
- [x] **Пакетная докачка дискографий** — ввод названия исполнителя или альбома для скачивания всех его релизов одной кнопкой.
